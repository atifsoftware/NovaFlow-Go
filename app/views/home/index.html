Modern Core Engines

NovaFlow Go provides robust, zero-dependency built-in modules designed for production grade stability and clean code layout.

🛡️

Middleware Kernel

Define global, route groups (web, api), and route-level aliases in a centralized `app/middleware/kernel.go` class. Decouples middleware implementations from route mappings.

📊

ActiveRecord ORM

Parameter-bound QueryBuilder securing your SQL execution. Support for full Transaction (Tx) commit/rollback, Left/Right/Inner Joins, Deep Cloning, and column Plucking.

🚨

Intelligent Debugger

Local panic recovery interceptor rendering visual dark-themed HTML screens. Highlights source context lines, filters sensitive credentials, and generates quick search tools.

✓

Struct Validation

Perform validation on struct fields using Go reflection and struct tags. Supports required fields, email parsing, numeric parameters, string limits and number range restrictions.

📝

Structured logging

Utilizes native Go standard `log/slog`. Autodetects local text formatted environment versus cloud JSON log specifications, rendering clean HTTP response metrics.

📂

Batch Migrations

Robust DB schema migrations manager supporting UP and DOWN block compilation. Rollback single increments or groups of migrations cleanly.

Follow a predictable, high-performance MVC workflow designed to process incoming requests cleanly and serve responses instantly.

4. Route Group MW

app/controllers/product_controller.go
package controllers

import (
    "novaflow/core"
)

func (ctl *ProductController) Store(c *core.Context) {
    // 1. Bind request schema using struct tags
    var req CreateProductRequest
    if err := c.BindJSON(&req); err != nil {
        c.JSONError(400, "Invalid JSON payload")
        return
    }

    // 2. Validate struct against tags
    validator := core.NewValidator(nil).ValidateStruct(req)
    if !validator.Passes() {
        c.JSON(422, map[string]interface{}{"errors": validator.Errors()})
        return
    }

    // 3. Database operations with ORM QueryBuilder
    newID, err := ctl.db.Table("products").Insert(map[string]interface{}{
        "name":  req.Name,
        "price": req.Price,
    })

    c.JSONSuccess(map[string]interface{}{"id": newID})
}
